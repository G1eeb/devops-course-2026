# Мой пет-проект

## Идея

Веб-приложение для отслеживания сериалов - личный трекер вместо заметок в телефоне.

## Стек

**Frontend**
- React + TypeScript
- Vite (сборка)
- Tailwind CSS (стили)
- React Router (навигация)
- TanStack Query (работа с API)

**Backend**
- Node.js + Express
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT для авторизации

**Инфраструктура**
- Docker + docker-compose (локальный запуск)
- GitHub Actions (CI)
- Vercel (frontend) + Railway (backend + БД)

**Инструменты**
- ESLint + Prettier
- Vitest + React Testing Library
- Git (ветки по схеме `feature/*`, `bugfix/*`)

## Цель

Сделать удобный трекер сериалов, которым буду пользоваться сам и который заменит заметки.

## Сроки реализации
- MVP: 2 недели
- Первая версия: 1 месяц
