# Мои цели на семестр

1. Освоить основы Docker и научиться контейнеризировать свои приложения (создавать Dockerfile, собирать образы, запускать контейнеры).

2. Научиться настраивать CI/CD пайплайны через GitHub Actions — автоматизировать сборку, тестирование и деплой.

3. Изучить базовые команды Linux (работа с файловой системой, управление процессами, настройка сетей) для уверенной работы на серверах.
