# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- Объем памяти: 2048 МБ (2 ГБ)
- Количество ядер процессора: 2 vCPU
- Объем дискового накопителя: 25 ГБ, динамически расширяемый VDI
- Операционная система: Ubuntu Server 24.04 LTS (без графического окружения)

## 2. Сетевые интерфейсы
- Сетевой адаптер 1 (NAT):
  - IP-адрес: 10.0.2.15/24 (интерфейс enp0s3)
  - Назначение: исходящий доступ гостевой ОС в сеть Интернет, получение обновлений пакетов.
- Сетевой адаптер 2 (Host-only):
  - IP-адрес: 192.168.56.101/24 (интерфейс enp0s8)
  - Назначение: изолированная локальная сеть между хостом и ВМ, прямое обращение к сервисам без выхода во внешнюю сеть.

## 3. Правило проброса портов
- Наименование правила: ssh
- Протокол: TCP
- Адрес хостовой системы: 127.0.0.1
- Порт хостовой системы: 2222
- Адрес гостевой системы: (пусто / 0.0.0.0)
- Порт гостевой системы: 2222 (перенаправлено с 22 порта в рамках харденинга)

## 4. Учётные записи
- `student`:
  - Назначение: учетная запись первичной установки системы
  - Принадлежность к группам: student, sudo, adm, cdrom, dip, plugdev, lxd
  - Способ аутентификации: парольный (локально через консоль)
- `devops`:
  - Назначение: целевая административная учетная запись управления узлом
  - Принадлежность к группам: devops, sudo
  - Способ аутентификации: аутентификация по открытому ключу Ed25519 (~/.ssh/authorized_keys); парольный вход по SSH отключен

## 5. Служба SSH
- Порт прослушивания: 2222
- Расположение конфигурационных файлов:
  - Резервная копия: `/etc/ssh/sshd_config.backup`
  - Файл переопределения параметров: `/etc/ssh/sshd_config.d/99-hardening.conf`
- Измененные директивы:
  - `Port 2222` — нестандартный порт
  - `PermitRootLogin no` — запрет входа суперпользователю root
  - `PasswordAuthentication no` — отключение аутентификации по паролю
  - `PubkeyAuthentication yes` — разрешение ключевой аутентификации
  - `PermitEmptyPasswords no` — запрет пустых паролей
  - `MaxAuthTries 3` — ограничение числа попыток аутентификации
  - `LoginGraceTime 30` — таймаут сессии аутентификации (в секундах)
  - `AllowUsers devops` — ограничение списка допущенных пользователей
  - `X11Forwarding no` — отключение пересылки графического протокола X11
  - `ClientAliveInterval 300` и `ClientAliveCountMax 2` — проверка активности сессии
- Управление службой: `ssh.socket` отключен (`disable --now`), служба переведена на юнит `ssh.service`.

## 6. Правила межсетевого экрана
- Политики по умолчанию:
  - Входящие соединения (incoming): `deny`
  - Исходящие соединения (outgoing): `allow`
- Перечень правил:
  - `2222/tcp LIMIT` (SSH rate-limited: ограничение частоты соединений до <6 за 30 секунд)
  - `80/tcp ALLOW` (HTTP для веб-сервера Nginx)
  - `443/tcp ALLOW` (HTTPS для защищенного веб-трафика)

## 7. Снимки состояния
- `01-clean-install` — исходное состояние после установки ОС Ubuntu 24.04 и обновления пакетов.
- `02-keys-configured` — создана учетная запись `devops`, настроена беспарольная аутентификация по ключу Ed25519, проверены права 700/600, настроен `~/.ssh/config` на хосте.
- `03-ssh-hardened` — выполнен харденинг SSH (порт 2222, отключен root и пароли), актуализирован проброс портов VirtualBox, настроен UFW.

## 8. Веб-сервер
- Устанавливаемый пакет: `nginx` (версия 1.24.0 из стандартных репозиториев Ubuntu 24.04).
- Путь к конфигурационному файлу ресурса:
  - Основной файл: `/etc/nginx/sites-available/devops-site`
  - Символическая ссылка активации: `/etc/nginx/sites-enabled/devops-site`
  - Стандартный ресурс отключен: ссылка `/etc/nginx/sites-enabled/default` удалена.
- Каталог публикуемого ресурса: `/var/www/devops-site`
  - Владелец и группа: `devops:devops`
  - Права каталога: `755` (`drwxr-xr-x`)
  - Права файлов (`index.html`, `404.html`): `644` (`-rw-r--r--`)
- Пути к ключевому материалу TLS:
  - Сертификат: `/etc/ssl/certs/devops.crt` (права `644`, владелец `root:root`)
  - Закрытый ключ: `/etc/ssl/private/devops.key` (права `600`, владелец `root:root`)
- Команда формирования самоподписанного сертификата:
  ```bash
  sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout /etc/ssl/private/devops.key \
    -out /etc/ssl/certs/devops.crt \
    -subj "/CN=devops.local" \
    -addext "subjectAltName=DNS:devops.local"
