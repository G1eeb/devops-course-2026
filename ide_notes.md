# IDE vs CLI: заметки

## Удобно в VS Code
1. Визуальный diff — сразу видно, что изменилось в файле, без `git diff`.
2. Кнопки commit/push/pull — не нужно помнить команды.
3. Встроенный редактор конфликтов при merge — можно выбирать строки мышкой.

## Удобнее в терминале
1. Интерактивный rebase (`git rebase -i`) — в VS Code его нет из коробки, а в терминале он делается за секунды.
